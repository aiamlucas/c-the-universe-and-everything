how it works
  • 1Loop i = 0..SCREEN_RAYS. Map each ray to camera_x ∈ [-1, +1] — same formula as draw_3d.
  • 2Compute ray_dir = dir + cplane × camera_x. Cast with DDA — same init_ray + step_ray as 3D render.
  • 3After DDA: perp_dist = ray_dist - delta_dist — exact distance to wall face.
    Then: ray_screen_y = WIN_HEIGHT/2 - (WIN_HEIGHT/perp_dist)/2 — top of the wall strip.
  • 4Draw green line from (WIN_WIDTH/2, WIN_HEIGHT-1) to (col_x, ray_screen_y). All lines fan from the same origin.
camera_x = 2.0 × i / (SCREEN_RAYS-1) - 1.0
col_x = i × WIN_WIDTH / (SCREEN_RAYS-1)
ray_screen_y = WIN_HEIGHT/2 - (WIN_HEIGHT/perp_dist)/2
